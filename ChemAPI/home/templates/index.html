📖 Additional Information

Why POST Requests?

Chemical structures (SMILES) often contain special characters like brackets [], plus signs +, and minus signs - that can cause issues when included in URL paths. POST requests with JSON bodies handle these characters reliably.

Error Handling

All endpoints return appropriate HTTP status codes:

  • 200 OK - Successful prediction
  • 400 Bad Request - Invalid input (missing structure, invalid JSON, or invalid adduct type)
  • 500 Internal Server Error - Prediction or model loading failure
